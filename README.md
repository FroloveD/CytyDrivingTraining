# CytyDrivingTraining

Тренажёр вождения для автошкол. Имитирует реальные маршруты и городские парковки, оценивает ошибки ученика и показывает результат.

Репозиторий: [https://github.com/FroloveD/CytyDrivingTraining](https://github.com/FroloveD/CytyDrivingTraining) (на момент создания пустой)

> Этот файл ведём как живую памятку. Каждое значимое решение, изменение структуры или смену этапа записываем в разделы ниже и в журнал изменений внизу.

---

## 1. Цель

Дать автошколам работающий тренажёр, на котором ученик отрабатывает:

- парковку (параллельную, задним ходом в бокс, перпендикулярную);
- движение по реальным маршрутам города с учётом светофоров, знаков и пешеходов.

Результат каждой попытки оценивается по понятным критериям, которые согласуются с инструкторами.

**Что тренажёр не делает:** не заменяет экзамен в ГАИ, пока это не подтверждено. В описаниях и маркетинге не заявляем обратное.

## 2. Ключевые решения

| Решение | Выбор | Почему |
| --- | --- | --- |
| Ядро | Веб-приложение: HTML, JS, Three.js | Один код для браузера, Windows-приложения и будущего планшета |
| Windows-оболочка | Tauri (запасной вариант: Electron) | Лёгкая сборка, быстрый запуск на школьных ПК |
| Модель автомобиля | Кинематическая модель «велосипед» | Достаточно для парковки и городской езды, без сложной физики шин |
| Параметры авто | Категория B: длина \~4,2 м, ширина \~1,8 м, база \~2,6 м, радиус поворота \~5,2 м | Ощущение управления близко к реальному |
| Карты | OpenStreetMap через Overpass API | Реальные дороги и разметка. Нужна атрибуция ODbL |
| Ввод | Общий слой ввода: `{ throttle, brake, steering, gear }` | Клавиатура, руль, педали и тач подключаются без переписывания логики |
| Оценка | Набор критериев, сверяется с инструкторами | Оценка должна совпадать с тем, что ученик увидит на экзамене |

---

## 3. Порядок ввода

1. **Сейчас:** клавиатура. W/S газ и тормоз, A/D руль, R и D передача.
2. **Позже:** руль и педали через USB, с учётом драйверов и совместимости моделей.
3. **Позже:** управление с планшета и телефона (тач).

Игровая логика получает только общую структуру ввода и не знает устройство.

## 4. Структура проекта (план)

```
src/
  input/        клавиатура; позже руль, педали, тач
  vehicle/      модель автомобиля (кинематика, габариты, коробка)
  world/        тестовая площадка: разметка, бордюры, боксы
  scenarios/    сценарии парковок и критерии оценки
  scoring/      подсчёт ошибок и баллов
  ui/           HUD, результаты, меню
src-tauri/      оболочка Windows-приложения
docs/           заметки для инструкторов, критерии оценки
```

## 7. Заметки по производительности

- Тестовая площадка и 3 парковки: нагрузка минимальная.
- Городские маршруты: упрощать геометрию из OSM, отрисовывать только близкие участки, проверять столкновения только с соседними объектами, использовать инстансинг для одинаковых объектов.
- Замерять FPS на школьном компьютере на каждом этапе, а не только на dev-машине.
